# Romantic Website for My Girlfriend

This is a beautiful, romantic website I created just for you. It's filled with love, memories, and heartfelt messages.

## How to View the Website

1. Open the `index.html` file in your web browser.
2. Or, if you have a local server, you can serve the files from the `romantic-website` directory.

## Customization

### Personalize the Content

1. **Names**: Replace `[Girlfriend's Name]` and `[Your Name]` in `index.html` with actual names.

2. **Messages**: Edit the text in the `<p>` tags within the sections to make it more personal.

3. **Memories**: Replace the placeholder images (`placeholder1.jpg`, `placeholder2.jpg`, `placeholder3.jpg`) with actual photos of your memories. Place them in the `romantic-website` directory.

### Adding Your Own Photos

- Save your favorite photos as `memory1.jpg`, `memory2.jpg`, etc.
- Update the `src` attributes in the HTML to match your image filenames.

### Colors and Styling

- Edit `styles.css` to change colors, fonts, or layout to match your preferences.

### Hosting

If you want to share this online:
- Upload all files to a web hosting service (like GitHub Pages, Netlify, etc.)
- Make sure to include all files: `index.html`, `styles.css`, `script.js`, and your images.

## Features

- Responsive design that works on mobile and desktop
- Animated heart in the hero section
- Interactive "Yes, Always!" button with a special message
- Floating hearts animation
- Memory gallery section
- Beautiful gradient backgrounds

Enjoy sharing this with your special someone! ❤️
